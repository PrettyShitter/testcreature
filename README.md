# AI Finder

Каталог и помощник для выбора AI-сервисов. Интерфейс сайта на английском языке.

## Что уже сделано

- Каталог AI-сервисов с поиском и фильтрами по изображениям, видео и разработке.
- Карточки сервисов с переходом на официальный сайт, подробностями, тарифами и доступными источниками данных.
- Подборки Top 3 по изображениям, видео и разработке.
- Сравнение двух сервисов по опубликованным ценам, лимитам и характеристикам. Если официальных данных недостаточно, сравнение соответствующего показателя недоступно.
- Workflow Builder для составления последовательности задач и подбора сервисов из каталога.
- Адаптивная верстка для мобильных устройств и компьютеров.
- Поиск каталога через серверный маршрут `/api/freeserp`, который обращается к публичному API FreeSERP.
- Чтение цен и характеристик с официальных страниц и документации сервисов через `/api/official-metrics`. Результат кэшируется на 30 минут.
- Автоматизированные проверки адаптера API и сценарии браузера.

## Как устроен сайт

Клиентская часть написана на React, TypeScript и Vite. Интерфейс получает каталог из FreeSERP API. Сравнение читает страницы цен и документацию сервисов, извлекает поддерживаемые показатели и показывает источник рядом с результатом. Workflow Builder использует поиск каталога для каждого шага.

Данные и верстка находятся в `src`. Список сервисов и источников сравнения задан в `src/tops.ts` и `api/official-metrics.ts`. Production-обработчики находятся в каталоге `api` и запускаются как serverless functions Vercel. Для локальной разработки маршрут сравнения подключен через Vite middleware, поиск проксируется через Vite proxy.

## Запуск

Требуется Node.js версии, совместимой с Vite 8, и npm.

```sh
npm install
npm run dev
```

Для локальной production-сборки:

```sh
npm run build
npm run preview
```

Проверки:

```sh
npm test
npm run test:e2e
```

## Публикация и адрес сайта

- Vercel: настроен для клиентской части и serverless functions каталога и сравнения. Сборка создается командой `npm run build`, статические файлы берутся из `dist`.
- VPS или другой Node.js-хостинг: можно разместить приложение и API на одном сервере, запуская серверную часть отдельно от статической сборки.
- Статический хостинг: подходит для интерфейса, но не для текущих серверных обработчиков. API потребуется разместить отдельно.
- Домен: можно подключить к Vercel, VPS или другому хостингу через настройки DNS у регистратора домена.

Проект опубликован на Vercel: https://testcreature.vercel.app/. Репозиторий подключен к Vercel, обновления ветки `main` публикуются автоматически. Собственный домен можно подключить в настройках проекта Vercel.

## Что предстоит сделать

- Подключить собственный домен при необходимости.

## Идеи для развития

Так же можно добавить более расширенное и корректное сравнение разных сервисов, а так же моделей, но не во всех docs присутствует такая информация, поэтому при желании можно вместо API использовать парсинг или скраппинг, чтобы получить нужную информацию и выводить её в вкладку сравнения/карточки сервисов/воркфлоу билдер.

## Основные файлы

- `src/App.tsx` и `src/style.css`: страницы, каталог, карточки, подборки и сравнение.
- `src/WorkflowBuilder.tsx` и `src/workflow.css`: конструктор рабочих процессов.
- `src/api.ts`: запросы к каталогу и нормализация результатов.
- `src/tops.ts`: сервисы, источники и метрики для сравнения.
- `vite.config.ts`: локальный proxy FreeSERP и обработчик чтения официальных страниц.
- `tests`: проверки API и браузерные сценарии.
